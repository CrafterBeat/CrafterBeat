## 如果今天有 2 小时或一个完整周末，应该做什么？

Today’s HN narrative was dominated by two policy posts and a memorial, but the real signal for a two‑hour build came from [@traceroute66](https://news.ycombinator.com/item?id=48698748), who dropped a sharp accusation on the 614‑point _Fintech Engineering Handbook_: “I think this ‘handbook’ was mostly written by an LLM.” That comment hits a deep fault line in AI‑content production right now: knowledge‑aggregation pieces are being stuffed with LLM output at speed, while readers’ alarm and desire to sniff out “AI slop” are spiking in lockstep. In the same thread, [@cirrhosis](https://news.ycombinator.com/item?id=48697476)’s defense (“it looks legit to me”) proves exactly that this sniff‑test has become a forced prelude to reading — before consuming a long article, people now ask, “Was this written by a person or generated by AI?” And Toolfinder’s comment added that such aggregations “appear a few times a year,” which means the traffic window for a single release is closing.

GitHub’s second‑fastest‑growing project, [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) (up 22,848 stars this week) — an agent that reads Twitter, Reddit, YouTube, and GitHub — reinforces this judgment: agents are being fed the entire internet, but nobody has strapped the most basic BS detector onto them.

Here’s what you can build today. A single‑page web tool that accepts arbitrary text input (user paste or URL), calls the Anthropic Messages API, and asks the model to return two structured fields: `humanness_score` (a 0–100 confidence score plus five specific textual features as evidence) and `llm_likely_model` (if it judges the text as AI‑generated, an educated guess at which model family). The front end uses Streamlit with zero backend dependencies; the API key gets provided by the user (your server never touches a line of text). This tool does not judge whether the content is “correct” — it judges whether the weaving style of the paragraph reads more like Claude or ChatGPT, or more like a human writing while drinking coffee at 3 a.m. It’s the productization of `traceroute66`’s comment: turning “I think this was written by an LLM” into a structured, reproducible, evidence‑chain quick verdict.

Two‑hour MVP stack: [Replit Agent](https://replit.com) or raw Streamlit + the `anthropic` Python SDK. The first move is writing the Anthropic Messages API system prompt — that’s the core engine of the whole product. The system prompt must force the model to inspect five dimensions: sentence‑rhythm variability (AI tends toward uniform sentence length), concrete‑entity density (humans drop real names/places/dates more often), frequency of logical connectors, contextual accuracy of specialized terms, and the embedding pattern of personal anecdotes. Output format is fixed JSON; the front end renders scores and evidence with simple color bars so a user can decide in under five seconds.

Why not build another version of _Fintech Engineering Handbook_? HN and Agent‑Reach’s star count have already answered: token compression and internet‑awareness are two validated tracks, and this week’s tens of thousands of stars mean that thousands of developers will clone, improve, and launch their own versions in the coming days. If you jump in now you’re just a follower, without the distribution leverage of an HN front‑page slot. The “AI text source detector,” on the other hand, is a demand that this week’s data has punctured but that nobody has productized yet — [@traceroute66](https://news.ycombinator.com/item?id=48698748)’s accusation rides on a 200+‑point post, and the exposure window is right now.

If you have more time over the weekend, expand the Streamlit single‑page into a paid API service: let other agents call your endpoint to pre‑check before they consume information. Price it at $9/month for 10,000 checks, anchoring it as a negligible complement to a developer’s daily token bill. The charge makes sense because agent operators need to prevent their own agents from making cascading bad decisions based on AI‑generated falsehoods — if a case like the LLM‑padded _Fintech Engineering Handbook_ happened in a compliance context, the loss would dwarf $9.

**Key Judgment**: The replicable form today is the “AI text source detector” — a single‑page web tool that accepts text input, calls the Anthropic Messages API for structured source analysis, and outputs a confidence score plus an evidence chain. Front end in Streamlit, backend API key provided by the user. Deploy on Streamlit Cloud with zero ops cost.

**Counter View**: This judgment might fail first at the sampling level — `traceroute66`’s HN comment got high upvotes, but similar needs have been raised at least three times in the last 12 months (GPTZero and its endless clones), and each time the tool slid from “fresh toy” to “inaccurate gadget” within three weeks, because the LLM’s own detection capability drifts with model updates, and human writing styles are being inversely assimilated by LLMs. If OpenAI rolls out a native “content source annotation” feature in next month’s model update, the value of a third‑party detector like this collapses inside 48 hours.

### Reusable Packaging Patterns

- **Right-click instant, system-level embedding**：Take the core capability of a CLI tool or online service and encapsulate it into an OS right-click menu, a keyboard shortcut, or a local overlay — killing upload anxiety and app switching. Examples: GetCompress, Goldfish, and PDFTools.
- **Many-to-one API routing & governance**：Build a unified access layer on top of a fragmented ecosystem, turning the complexity of technology choice into a single billing, unified management, and compliance buyer entry point. Examples: discode.ai, Zernio WhatsApp API, and Wirable.
